# 타입 선언

`type X = ...` 형식으로 쓴다. 타입 선언이 있으므로 LTIR만 배포해도 중간 언어로 기능한다.

타입 인자는 콤마로 구분해 선언한다.

```
type Either[A, B] = ...
```

적용도 콤마로 구분하며, 모든 인자를 한 번에 채운다. 부분 적용은 허용하지 않는다.

```
Either[X, Y]
```

타입 인자의 kind는 기본적으로 `*`이며, 명시할 수 있다. 다인자 kind는 `* -> * -> *`처럼 쓴다.

## 함수 타입

`A/B -> C \ E` 형식으로 쓴다.

- `A`: 인자로 받아 소모하는 값의 타입이다(Linear Calculus).
- `B`: 계산이 종료될 때 인자 자리에 할당하는 값의 타입이다.
- `C`: 표현식 자체의 평가 결과 타입이다.
- `E`: 주입받아야 하는 effect의 타입이다.

effect 타입에는 abortable 여부를 명시한다. abortable한 effect의 수행 지점은 반환 지점일 수 있다. abortable하지 않은 effect의 핸들러는 반드시 재개해야 한다.

abortable한 effect를 수행하기 전에 `~p`는 반드시 `B` 타입 값으로 할당되어 있어야 한다. 검사기는 flow typing으로 각 abortable 수행 지점에서 `p`의 타입이 `B`인지 검사한다. 따라서 중단 시점에 원본 `A`를 보존하기 위한 dup은 하지 않는다.

## 전칭 타입

`forall T. X` 형식으로 쓴다. kind를 지정할 수 있고, 지정하지 않으면 `*`다. 전칭 타입과 타입 수준 람다(`type` 선언)는 별개의 타입으로 둘 다 존재한다.

## 재귀 타입

재귀 타입은 `mu X. τ`로 쓴다. iso-recursive다. `type` 선언은 자기 이름을 참조할 수 없으므로, 재귀는 `mu`로만 표현한다.

`mu X. τ` 타입의 값은 `unfold`로 풀고, `fold`로 감싼다.

```
unfold x
(fold x : T)
```

- `unfold x`: `x : mu X. τ`이면 결과 타입은 `τ[mu X. τ / X]`다. `x`의 타입에서 결과 타입이 정해지므로 타입을 명시하지 않는다.
- `(fold x : T)`: 풀린 타입에서 원래의 `mu` 타입을 복원할 수 없으므로 대상 타입 `T`를 명시한다. `T`는 별칭을 펼친 결과가 `mu X. τ`여야 하고, `x`의 타입은 `τ[mu X. τ / X]`와 일치해야 한다. 어긋나면 ICE다.
