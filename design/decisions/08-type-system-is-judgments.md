# No type plugin — a type system is its judgments

There is no "type plugin". A type system is the judgments a definition
declares — nothing else. Judgments run on a generic relational engine
that solves goals, unifies, and builds real derivation trees; the engine
knows nothing about Lumo. Lumo v1's judgments implement Fω + spine-local
bidirectional inference + capability rows. Failed premises map to
diagnostic templates; successful derivations power explanations and LSP
hovers; every derivation is a salsa query.
