# RFC 0050 — Impl elaboration, slice 4: generic inherent impls

Settled 2026-07-12. `impl[T] List[T] { fn map[R](self: List[T],
mapper: (T) -> R): List[R] = … }` — the form that unblocks `List.map`,
the last unported stdlib item.

## Σ signatures carry binders

Every `Σ.Op` value becomes `Sig(binders, type)` — the binder-name list
(impl-level ++ method-level) plus the op's comp type, with binder
occurrences as plain named types. Ground caps and D-48/49 instances
are the `Sig([], t)` degenerate case, so everything stays uniform.

Two judgment rules change, mirroring how `Δ.Variant` already handles
generic data:

- **Checking the impl** (`clauses_check`): the clause body checks
  against the sig type *as stored* — binder names stay rigid named
  types (skolems). A `map` body that secretly returns `List[Number]`
  fails to unify with `List[R]`.
- **Using a method** (`infer_C SelC`): the sig instantiates all
  binders with fresh variables per use site (`inst`, the same
  machinery as forall types and data ctors), so
  `t.map(mapper)` inside `map`'s own body — and every caller — gets
  its own `?T`, `?R`.

The instance def stays `def __impl_List = (bundle {…} : List_impl)`;
`SelC` keys Σ by cap name only, so the value's type needs no
polymorphism carrier — `NamedTypeV` never grows a forall. The
`{T}_impl` / `{Cap}_{T}` *naming* survives this slice: replacing it
with structured cap type-args needs Σ keys that unify on args without
rigidifying skolems, a design of its own — deferred with generic
*typeclass* impls (`impl[A] List[A]: Functor`), which still error.

## Elab: two gaps the body exposed

- **Match binders join the syntactic scope.** `t.map(mapper)` inside
  `.cons(h, t) => …` needs `syn_type(t) = List`. Binder types derive
  from the variant decl: field type-constructor heads are recorded
  per *tag* at init (`None` when a tag is ambiguous across data
  decls), and `rule_match_arm` pushes binder→head-name pairs around
  the body elab.
- **The syntactic table stores type-constructor heads.** `xs:
  List[Number]` now contributes `xs → List`, and `map`'s return
  `List[R]` contributes `List`, so chains like `xs.map(f).map(g)`
  dispatch. Ground names are unchanged (their head is themselves).

## Judge driver

- `seed_inherent` accepts generic heads: self's type is the head as
  written (`List[T]`), other params/returns spell binders as named
  types, and generic methods are no longer skipped.
- **Γ pre-seeds every impl def** (`__impl_List : List_impl`) before
  the def loop: a self-recursive method body references its own def,
  which is otherwise not yet in Γ. The def's bundle check still runs
  and still verifies the annotation; the later Γ push is a harmless
  shadow.

**Deferred**: generic typeclass impls and structured cap type-args
(above), bounded binders, dispatch on non-head type structure.
