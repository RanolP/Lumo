# RFC 0004 — Diagnostics live in the DSL

Diagnostic message templates are written in the definition files, attached
to rules, so messages live next to the logic that fires them and cannot
drift. (Exact attachment point inside `head := body` judgment rules is
still open — see the type chapter's open questions.)

**Deferred (see 26):** for now failures bail with a generic message; the
template design resumes later.
