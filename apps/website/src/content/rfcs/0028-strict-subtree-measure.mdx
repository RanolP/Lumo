# RFC 0028 — Strictly decreasing = strict subtree of the matched pattern

Confirmed: "only strictly decreasing allowed" means a recursive call
(elab's `to`, judgment recursion) may only take a **strict subtree of the
matched pattern**, which guarantees termination. Also confirmed: the file
kinds are `*.elab.langue` and `*.type.langue` (dictated `*.elab.lumo` and
`LIR.ty.langue` were shorthand/typos).
