# RFC 0000 — The RFC process

Substantial changes to Lumo are recorded as short design documents before they
are implemented.

Historically these live as numbered decision files in
[`design/decisions/`](https://github.com/RanolP/Lumo/tree/main/design/decisions)
in the repository (D-01 and onward). Going forward, proposals that deserve a
public write-up are published here as MDX files under
`apps/website/src/content/rfcs/`.

An RFC is deliberately lightweight:

1. State the problem and the locked decision.
2. Show the surface syntax and the elaboration it desugars to.
3. List what is explicitly deferred, so scope stays honest.

Nothing is stable yet; every RFC can be superseded by a later one.
