# RFC 0005 — No imports — cat + stdlib + DCE

A definition is a multi-file Langue project with kind-suffixed files
(`<name>.langue` manifest, `*.syn.langue`, `*.elab.langue`,
`*.type.langue`). `langc` concatenates every file under the project root,
together with the Langue stdlib, into **one global namespace**: no `use`,
no forward declarations, order-free visibility. Unused items are
dead-code-eliminated instead of erroring. Two same-named items are an
error, except designed **additive merges** (same judgment, same language,
same from/to elab block across files), checked globally after the merge.
